# Story Consistency Monitor（本地版）

续写或改稿前执行。

## 必读文件

- `novel/设定.md` — 人设、金手指、时间线
- `novel/大纲.md` — 章节计划
- 最近 2～3 章正文

## 核对项

| 类别 | 检查 |
|------|------|
| 人名 | 主角、称呼（清清/清姐）、亲戚姓 |
| 时间 | 重生日期、倒计时天数、大纲 Day 对齐 |
| 金手指 | 纯重生不能突然出现系统/空间 |
| 地理 | 602、仓库、便利店位置 |
| 物资 | 金额、囤货量是否暴涨无解释 |

## 输出

列出矛盾点 → 建议改设定或改正文 → 再写新章
